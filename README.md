# CostTracker – the cost tracking calendar

A prototype that runs as a home-screen app on iPhone, hosted with GitHub Pages:
**https://steffiwallace.github.io/cost-calendar/**

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole app, including the home screen icon |
| `support.js` | The engine that runs the app's screens |
| `sw.js` | Lets the app open offline, and always fetches the newest version when online |
| `apple-touch-icon.png` | A spare copy of the app icon |
| `README.md` | This file |

## Updating

Upload changed files on the repository's main page with **Add file → Upload files**, then commit. Before you commit, check each name is exact (`index.html`, not `index (2).html`). The site updates a minute or two after the green tick on the **Actions** tab.

Your data is saved on each phone, not here. Uploading new files doesn't erase it.
